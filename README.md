# 📊 Área Comercial - Power BI

Este projeto apresenta um dashboard interativo desenvolvido no Power BI, focado na análise de indicadores comerciais.

## 🖼️ Visual do Dashboard

Dashboard [(imagens/)](https://github.com/hugo-caixeta/Dashboard_area_comercial_powerbi/tree/d5739562339595c2354a0d3d04550734732c1390/imagens)

## 📌 Sobre o Projeto

O relatório é focado nos principais KPIs da área comercial, como:

- Volume de vendas
- Ticket médio
- Taxa de conversão
- Ciclo de vendas
- Retenção dos clientes
- Lucratividade
- Produtividade da equipe de vendas
- Satisfação do cliente

## 🧰 Ferramentas utilizadas

- Power BI
